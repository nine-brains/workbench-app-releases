# Workbench

**[Download the Workbench for Windows](https://github.com/nine-brains/workbench-app-releases/raw/main/Workbench-setup.exe)**

1. Open the downloaded file. Windows may say the app is unknown: click **More info**, then **Run anyway**.
2. Open the Workbench and paste the code from your invitation.

The app updates itself. This repo only holds the newest installer; the code is private.

---
